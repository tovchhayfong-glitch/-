# Khmer Couture website — GitHub Pages

This is a static website package. It contains the homepage, fitting booking page, contact page, and all image assets.

## Publish with GitHub Pages
1. Extract every item in this ZIP.
2. Upload `index.html`, `booking.html`, `contact.html`, and the `assets` folder to the root of your GitHub repository.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select your main branch and the `/(root)` folder, then save.
5. Wait for GitHub Pages to publish the site. Open the URL shown in the Pages settings.

Keep the `assets` folder beside the three HTML files so the photos and logo load correctly.
